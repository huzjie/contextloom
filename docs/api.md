# REST API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /health | 健康检查 |
| POST | /documents/ingest | 摄入文档 |
| POST | /queries/search | 检索 |
| POST | /queries/ask | 问答 |
| POST | /collections | 创建知识库 |
| GET | /collections | 列出知识库 |
| GET | /models | 当前模型信息 |
| GET | /admin/stats | 统计 |

交互式文档见 `/docs`（Swagger UI）。
